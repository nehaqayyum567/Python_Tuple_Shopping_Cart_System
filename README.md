# 🛒 Python Tuple Shopping Cart System

## Overview

This project is a simple command-line Shopping Cart System developed in Python using tuples. It allows users to select items from a predefined menu, checks item availability, calculates the total bill, applies a discount code, and displays the final amount.

## Features

- Store menu items and their prices using tuples
- Accept user input for three food items
- Validate item availability
- Calculate the total bill based on selected items
- Apply a 10% discount using the discount10 code
- Display the final bill
- Print a thank-you message after completing the order
